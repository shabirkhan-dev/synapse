# Code of Conduct

Synapse follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, welcome newcomers, and keep criticism about the work.
Harassment, personal attacks and discrimination are not acceptable anywhere in the project's
spaces (issues, pull requests, discussions and chat).

## Reporting

Report unacceptable behaviour to the maintainers privately through GitHub (for example by
contacting [@shabirkhan-dev](https://github.com/shabirkhan-dev)). Reports are kept confidential.
Maintainers may remove comments, lock threads or ban participants who break these rules, following
the Contributor Covenant's enforcement guidelines.
