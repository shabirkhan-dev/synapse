## What

The console's browser flows (sign-in, sign-up, verify, reset, documents, two tabs) were checked
with throwaway scripts; nothing guards them in CI.

## Why / Context

Roadmap Phase 3 row `tests/`. Auth and session handling (ADR-0007) are easy to break silently.

## Proposal or Ask

`tests/e2e/` with `@playwright/test`: start Postgres, the API (dev email log) and the console, run
the flows above; CI job with `--trace off`. Later: load and chaos suites.

## Scope

**In scope:**

- e2e suite, helpers (read emailed links from the API log), CI job

**Out of scope:**

- load / chaos tests (later cards)

## Validation

- suite passes locally and in CI; a deliberately broken flow fails it

## Resolution

Done in commit `test(e2e): add a playwright suite for the console and api`.

- `tests/e2e` workspace (`e2e`, `@playwright/test` 1.63.0 = the sandbox's preinstalled Chromium): `playwright.config.ts` starts a fake OpenAI-compatible model server (`:5601`), the API from source (`:8100`; `support/prepare-database.ts` first migrates `E2E_DATABASE_URL`, clears `auth_rate_limits` and resets the log, then its stdout is the email log) and the console built for that API (`:3100`). Helpers: `support/mail.ts` (newest emailed link per address), `support/accounts.ts` (API sign-up, form sign-in).
- Specs (5 tests): signed-out redirect; sign-up → cookie is httpOnly/Strict/`/api/v1/auth` and nothing readable in storage → reload → verify link → sign-out clears cookie; two tabs reloading together ×3; forgot → reset → reused link refused → old password refused → new works; workspace: no-documents answer → add document → Ctrl+Enter → cited answer → `[1]` → provenance → rating 200.
- Root `bun run test:e2e`; the package script is `e2e` (not `test`) so `turbo run test` does not start browsers. CI job `e2e` (pgvector service, `playwright install --with-deps chromium`, report + API log uploaded on failure).
- **Validation:** 5 passed locally in 41 s against pgvector 0.8.7. **Deliberately broken:** with the cross-tab Web Lock removed from the console's refresh, the two-tab test fails (second tab signed out after reuse revocation); restored.
- **Not done:** Firefox/WebKit, load/chaos/security suites; the CI job itself has not run yet (first push runs it).
