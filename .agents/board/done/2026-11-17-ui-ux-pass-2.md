## What

The human asked to improve the UI/UX further. Review every workspace page as rendered (desktop and
phone, light and dark, with data) against the `better-*` skills and fix the ranked findings.

## Why / Context

Phase 5 added many screens and controls (palette, follow-ups, pickers, web pages, judged runs) since
the last full review (syn-065).

## Proposal or Ask

Screenshot sweep → one ranked findings table (better-interface) → fix HIGH and MEDIUM findings →
re-shoot.

## Scope

**In scope:** apps/console, shared components in packages/ui. **Out of scope:** new features.

## Validation

Console tests, e2e, before/after screenshots.

## Resolution

Landed in `feat(ui): inter, flat #1c1c1c surfaces, 14px controls and a breadcrumb shell` (on `main`).

Mid-way the human set the direction: Inter (or Apple's font) with −0.15px tracking, dark #1C1C1C,
text #E5E5E5 / #A1A1A1, HugeIcons, radii 6/8/12px or full, and a flat bordered reference UI.

Review (better-interface), rendered sweep of 13 pages × desktop light/dark × phone, findings fixed:

| Severity | Finding | Fix |
| --- | --- | --- |
| MEDIUM, systemic | Body, labels, inputs, buttons, tables at 12px (base-mira `text-xs`) next to 15px nav | Shared components at 14px; controls 36px; hints stay 12px |
| MEDIUM, systemic | Mixed control heights in one row (36px inputs, 28–32px buttons) | Default button 36px = input; small 32px |
| MEDIUM | Tokens off the requested spec (near-black frame, inset panel, accent glow, 10px-based radii) | Tokens: #1C1C1C flat, #2B2B2B borders, 6/8/12px; plain sidebar + bordered sticky header |
| MEDIUM | Two nested `<main>` landmarks (shadcn `SidebarInset`) | `SidebarInset` is a `div` |
| MEDIUM | Option groups as loose ghost buttons (Top k, time range) | Shared `SegmentedControl` (track + raised option, `aria-pressed`), fits 320px |
| LOW | Approvals: bordered items inside a card | Divided rows |
| LOW | Usage tiles repeat the number below it | Exact count only when the value is rounded |
| LOW | Circuit states as grey badges | `StatusDot` (dot + label) |
| LOW | Sign-in on an accent gradient | Plain background |
| LOW | Drop zone's main line at 12px | 14px, hint 12px |

Contrast measured: #E5E5E5 on #1C1C1C 13.5:1; #A1A1A1 on #1C1C1C 6.6:1, on #262626 5.9:1.
Not changed: input borders (#333 on #1C1C1C, 1.35:1) as before; the generated input-group lint
warnings.

Validation: console 106 pass; e2e 24 pass (layout at 320px, account, usage re-run after fixes);
before/after sweeps in light and dark, desktop and phone.
