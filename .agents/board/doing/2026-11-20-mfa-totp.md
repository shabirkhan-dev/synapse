## What

Users can turn on TOTP; sign-in then asks for a 6-digit code, with one-time recovery codes.

## Why / Context

Gap review 2026-11-19 (item 5): no MFA.

## Proposal or Ask

RFC 6238 in `@synapse/security` (no new SDK), secret encrypted at rest, rate-limited code checks, recovery codes hashed. Done with unit vectors from the RFC, API tests and an e2e that enrols and signs in.
